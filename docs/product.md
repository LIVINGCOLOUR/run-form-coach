# 製品として決まっていること

## 誰に売るか

- 本線は、トレッドミルのカメラ版。24時間ジムのチェーン本部に、1店舗月1万円前後で売る。
- パーソナル系のジムと、路上向け（センサー4個）は外した。

## 料金の形

| 入り口 | 料金 | 役割 |
|---|---|---|
| スマホ1台 | 無料 | 走っている最中の声かけを体験してもらう入口 |
| トレッドミルのカメラ（家のトレッドミルも可） | 月1,000円 | 姿勢まで見られる本命 |
| センサー | 別売りの買い切り | 路上・トラックで姿勢まで見る |
| ジムの会員 | 無料（ジムが払う） | 無料版の人がジムへ行く流れを作る |

## 無料のスマホ版

- 置き場所は腰（ウエストポーチ・ランニングベルト）だけ。ベスト・胸・リュックは対象外。使うのは外を走るときだけで、トレッドミルではカメラ版を使う。
- 声で直すのはピッチ1つに絞る（仕様は `docs/phone-spec.md`）。
- 姿勢はほとんど見えない。だからこそ精度が要る（外れた声をかけると戻ってこない）。走っている最中と走った後に、「姿勢はトレッドミルやセンサーで見られる」と正直に見せる。
- 画面が消えても動かすため、iPhone アプリにする（Capacitor などで今のウェブアプリを包む）。自分で試すだけなら App Store の審査は要らない（Xcode で入れる）。
- Web Bluetooth は Mac・Android の Chrome だけで、iPhone のブラウザでは使えない。

## 競合で押さえておくこと

- StrideCoach は、スマホではなく AirPods の中のセンサーで頭を測っている。

## これからの声かけの工夫（まだ作っていない）

- 言い方を段階的に変える
- その人がいつも崩れる時刻の少し前に声をかける
- 「外れた」音と「戻った」音を続けて鳴らさない

作ったもの：「声なしで保てた時間」を結果の主役にする、1回の走りで直す項目は1つ（ランナーのレベル）。
