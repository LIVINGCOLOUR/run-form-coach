# 実機テスト②の手順（トレッドミル、1人・約20分）

スマホ版（腰）のピッチの知らせ（声とメトロノーム）が、iPhone の Safari で決めたとおりに鳴るかを確かめる。
決まり（いつ何が鳴るか）は `docs/phone-spec.md` の機能2と「知らせ方の決まり」、数字は `src/core/params.ts` の `TONE`・`METRONOME`。
カメラ版は要らない（ピッチの精度はテスト①で見る）。画面はつけたままでよい。

## 知らせの流れ（確かめる答え）

1. 走り始めて3分で、仮の基準（30秒〜3分の平均ピッチ）ができる。画面のピッチの欄に「基準 ○○ 歩/分（仮）」と出る
2. ピッチが基準より5%以上下がった状態が続くと（6〜10秒ほどで）、**1回目だけ**「足の回転が落ちています。小さな歩幅で、軽く刻んでください。」と言い、**言い終えてから**基準のテンポのメトロノームが鳴る（4拍ごとに高い音、最大8小節＝170歩/分で約11秒）
3. メトロノームに合わせてピッチが戻ると、7〜9秒ほどで止まる（「戻った」の言葉はない）。戻さなければ8小節で止まる
4. 下がったままなら、前の知らせから30秒ごとに、**言葉なしで**メトロノームだけが鳴る。4回目からは間が60秒・90秒…とのび、最長180秒
5. 12分を過ぎると、基準が5〜12分の平均に置き換わる（「（仮）」が消える）。5〜12分の間でわざと落とした秒は入れない

## 用意するもの

- iPhone（Safari）とランニングベルト。音量ボタンで音量を上げておく
- 消音スイッチは**オン（消音）にしておく**（それでも鳴るかを見る）
- できれば、ほかのアプリ（ミュージックなど）で音楽を流しておく（止まるか・重なるかを見る）
- イヤホンを使う人は、イヤホンでも1回やる

## 走る（合計 約20分）

スマホ版は、ホームの「トレッドミルで試す（実機テスト）」から始める（「スマホ版をはじめる」は外用で、GPS が取れないと判定を止めて鳴らない）。
速さはテスト①と同じで、最後まで変えない。区間の間で休まなくてよい。

| 順 | 時間 | 走り方 | 確かめること |
|---|---|---|---|
| 1 | 0〜5分 | いつもの走り | 3分で「基準 ○○ 歩/分（仮）」が出る。声もメトロノームも鳴らない |
| 2 | 5〜6分 | 歩幅を大きくしてピッチをはっきり落とす（1割ほど） | 言葉が1回 → 言い終えてからメトロノーム。言葉とクリックが重ならない |
| 3 | 鳴ったらすぐ | メトロノームに合わせて足を刻む | 合わせて10秒ほどで止まる |
| 4 | 7〜9分 | もう一度落とし、メトロノームが鳴っても**合わせずに**落としたまま | 言葉は言わない。8小節で止まり、30秒後にまた鳴る |
| 5 | 9〜12分 | いつもの走り | 鳴らない |
| 6 | 12〜15分 | いつもの走り | 12分を過ぎると「（仮）」が消える |
| 7 | 15〜17分 | もう一度落とす | 言葉なしで、メトロノームだけ鳴る。テンポが新しい基準になっている |
| 8 | 17〜18分 | 戻す | 止まる |

## 見るところ

- **テンポ**：メトロノームを聞きながら足を合わせ、画面のピッチが「♪ メトロノーム ○○」の数字に近づくか。クリックの間隔がよれないか（とくに画面の表示が変わる瞬間）
- **声と重ならないか**：言葉の途中でクリックが鳴らないか。付け方の確認の声（あれば）とも重ならないか
- **音量**：走っている最中に、クリックがはっきり聞こえるか（小さい・大きい・耳に痛い）。外の音を想像して足りそうか
- **消音スイッチ**：オンでも声とメトロノームが鳴るか
- **ほかのアプリの音楽**：スマホ版を始めた時点・声が出た時点で、音楽が止まるか、小さくなるか、重なって鳴るか。止まったら、あとで再開するか
- **止まり方**：戻したら止まるか。戻さないときは8小節で止まるか。走りを終えると（✕ や「終える」）すぐ止まるか

## 走り終わったら

1. 「終える」→ 結果の画面で「知らせた回数（声 1 · メトロノーム ○）」を見る
2. 結果の画面の「調整用の記録を書き出す」。記録の `events` に、話した言葉と `tone:on:cadence:テンポ`・`tone:off:cadence`・`ref:later:ピッチ` が時刻つきで入る
3. 書き出したファイルと、上の「見るところ」で気づいたこと（とくに音楽が止まったか、音量）を渡す

## 分かっていて、まだ決めていないこと

- **ほかのアプリの音楽は止まる見込み。** 声を消音スイッチがオンでも鳴らすため、音の種類を `navigator.audioSession.type = 'playback'`（`core/voice.ts` の `unlockVoice`）にしている。これは iPhone ではほかのアプリの音楽を止める種類。`'ambient'` にすると音楽と重ねて鳴らせるが、消音スイッチで鳴らなくなる。ウェブでは「音楽を少し小さくして重ねる」はできない（iPhone アプリにすれば、音楽を小さくして重ねる設定がある）。このテストの結果で、どちらにするかを決める
