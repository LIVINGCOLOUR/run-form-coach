# 走りながらの声かけの仮想実験（多くのランナー）

研究データ（Riglet ら 2024、CC0、https://doi.org/10.6084/m9.figshare.25592865.v1）の30人が、トレッドミルを楽なペースと速いペースで走った記録（それぞれ約1分）から、1歩きずつ切って並べ直した13分の走りを作り、仮想のスマホ（毎秒15コマ・点のぶれ・左右の取り違え）で映して、今のコーチ（src/modes/camera/coach.ts）にアプリと同じ間引きで通した。コーチは走り出しに正しいフォームの線（src/modes/camera/params.ts の FORM）と比べて整え、整えたあとの形で今日の基準を作る。仮想のランナーは声を聞いても直さない。首の角度の6秒平均が20°を超えて動く記録（BD004-楽）は、肩の関節の中心の推定がおかしいとみて除いた。崩しは3次元の点を動かして作ったもの（データに崩しの条件はない）。数分かけての揺れや疲れは元の記録に入らないので、実機の記録のばらつきに合わせたゆっくりしたずれを足した条件も並べた（{"neck":[1.8,3],"trunk":[0.35,3],"body":[0.4,120]}：[大きさ°, 続く秒]）。
限り：元の記録は1本あたり約1分なので、数分かけての変化（疲れ・服や光による推定のずれ）は「実機なみのずれ」で足した分しかない。崩しは作りもの（本当に上体を倒した走りは result-coach-vh.md、脚だけのデータでの腰は result-coach-rbds.md）。カメラ版はピッチを判定しないので、ピッチの崩しは試していない。
動かし方：RIGLET_DIR=<データ> npx vitest run --config sim/vitest.config.ts sim/coach.sim.ts
