# 厳しさ（レベルごとの線）の仮想実験

研究データ（Riglet 2024）の59本を、実機なみのゆっくりしたずれを足して仮想のスマホで映し、レベルごとの線（params.ts の STRICT）でコーチに通した。見る項目はすべて。誤った声は、今日の基準ができたあとの10分あたりの、基準からの崩れの声（カッコ内は声が1回でも出た走りの割合）。崩しは走り始めて250秒から60秒。「見つけた」は合う項目の声が60秒以内に出た走りの割合、カッコ内は声までの秒数の中央値。
動かし方：RIGLET_DIR=<データ> npx vitest run --config sim/vitest.config.ts sim/coach.sim.ts -t 厳しさ

「整える間」は走り出しに正しいフォームの線で言った声が出た走りの数、「線（あと）」は基準ができたあとに正しいフォームの線で言った声の10分あたりの回数（走りの数）。
