# 本当に上体を前に倒した走りを見つけるか（仮想実験）

研究データ（Van Hooren & Meijer 2024、論文は CC BY 4.0、データ https://osf.io/7qbxc/ は制限なしで公開）の16人の、秒速3.33mのふつうの走りと「少し上体を前に倒して」走った条件（それぞれ約1分）。ふつうの走りを1歩きずつ並べ直して250秒走り、そこから60秒だけ前に倒した走りに入れ替えて、今のコーチ（上級）に通した。頭の印がないので、頭の項目は声をかけないようにした。見つけた割合は、上体が本当に2°以上増えた15人（上体 平均 +6.7°・体全体 +2.2°）で数えた。誤った声は、ふつうの走りだけで作った13分の、基準ができたあとの10分あたり。
動かし方：VH_DIR=<データ> npx vitest run --config sim/vitest.config.ts sim/coach.sim.ts

| 置き方・ぶれ | 上体か体全体の声が出た | 声まで（中央値） | 誤った声（10分あたり 上体 / 体全体） |
|---|---|---|---|
| 基準（真横・1.2m・高さ80cm・ぶれ1%） | 93% | 15秒 | 0.51 / 0.32 |
| 実機なみのゆっくりしたずれを足す | 93% | 15秒 | 0.64 / 0.77 |
