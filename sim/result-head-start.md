# 走り出しから頭が前に出ている人を、整える間に知らせる線（仮想実験）

動かし方と限りは sim/head-start.sim.ts の先頭。研究データのふつうの走り 77本を 780秒にのばし、1本ごとに首の角度・頭の位置の真ん中を目当ての値にそろえて、アプリのコーチ（上級、間引きあり）に通した。線は首の角度と頭の位置の両方を越えたときだけ言う（16秒平均）。整える間は 3回まで（30秒あけて）、そのあとは 300秒に1回。

- よい例の真ん中：首 29.2°・頭の位置 33.8°。よい例の上の端：首 30.9°・頭の位置 37.8°。いつもの頭：首 33°・頭の位置 37°
- 「線の声」は頭の線で言った声、「崩れの声」は今日の基準・仮の基準からの頭の崩れの声（上級 +6°。線によらず、ふつうの走りの揺れで10分あたり約4回出る：sim/result-coach-strict.md）。直った声・ほめる声は数えない
- 整える間に気づいた：走り出して 10秒から 120秒の間に、頭の線の声が出た走りの割合（かっこは走り出しから声までの秒の真ん中）
- 直して戻る：いつもの頭で走り出し、70秒によい例の真ん中へ直し、420秒にいつもの頭へ戻す。直った：70〜420秒に「いいですね。その形です。」と言った割合。戻って気づいた：420秒より後に頭の声が出た割合
