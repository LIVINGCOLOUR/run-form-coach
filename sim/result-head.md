# 頭が前に出た量の判定のずれ（仮想実験）

研究データ（Riglet ら 2024、CC0、https://doi.org/10.6084/m9.figshare.c.7056797.v1）の23人の、立った姿勢と、トレッドミルを楽なペースで走った記録を、仮想のスマホで置き方を変えて毎秒15コマで映した。頭の印（耳の後ろ）と肩・股関節の中心が測られている。立った記録が1秒より短い人は除いた。
首の角度＝手前側の「肩→耳の前傾 − 腰→肩の前傾」（アプリと同じ定義）。ずれは「アプリ − 本当の値」の平均（カッコ内はずれの大きさの平均）。
声かけの割合は、6秒平均が線（5°）を越えた割合。「立った基準と比べる」が今のアプリ、「走り始めと比べる」は最初の25秒を基準にした案、「平均してから比べる」は1秒ごとに0で切らず、6秒平均を取ってから基準と比べる案。「頭を前に」は、首の付け根を中心に頭を10°前に回して作った走り（データに頭を前に出した条件はない）。
動かし方：RIGLET_DIR=<データ> npx vitest run --config sim/vitest.config.ts sim/head.sim.ts

本当の値（23人）：首の角度は、立った姿勢から走ると平均 -8.8°（人によるばらつき ±8.6°、いちばん小さい人 -23.8°・大きい人 13.1°）。声をかける線（5°）を越える人は 1人。
走り始めの25秒とそのあとの30秒の差：平均 +0.2°（±1.5）。頭を10°前に回すと、首の角度は平均 +6.8°（±6.8） 増える。
