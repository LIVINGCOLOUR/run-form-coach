# 上体の傾きの判定のずれ（仮想実験）

研究データ（Van Hooren & Meijer 2024、CC BY、https://osf.io/7qbxc/）の16人（Sub_18 は胸骨の印がないので除く）が、秒速3.33mでふつうに走った条件と、上体を前に倒して走った条件を、
仮想のスマホで置き方を変えて毎秒15コマで映し、アプリの上体の傾き・体全体の傾きと、声をかける割合（6秒平均が線を越えた割合）を出した。
ずれは「アプリ − 本当の値」の平均（カッコ内はずれの大きさの平均）。上体と体全体は、左右の真ん中を通る線で測る。
動かし方：VH_DIR=<データ> npx vitest run --config sim/vitest.config.ts sim/trunk.sim.ts

本当の値（16人の平均）：上体 ふつう 4.2° → 前に倒す 11.8°、体全体 ふつう 10.4° → 前に倒す 14.4°（声をかける線：上体 15°・体全体 14°）
