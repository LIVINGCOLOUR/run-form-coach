# 頭の正しいフォームの線の高さ（仮想実験）

研究データのふつうの走り 77本（Riglet の楽・速い、Van Hooren の時速12km）を10分あまり（780秒）にのばし、実機なみのゆっくりしたずれ（{"neck":[1.8,3],"trunk":[0.35,3],"body":[0.4,120]}）を足して、真横・1.2m・高さ80cm の仮想のスマホで映し、アプリのコーチ（上級、間引きあり）に通した。

研究データの頭の印は、アプリの点（MediaPipe の耳）より首の角度が小さく出るので、1本ごとに、ふつうに走った値の真ん中を自分の記録（2026-11-02 のふつうの区間の16秒平均の真ん中、首 42°・頭の位置 44°）にそろえた（足した量の真ん中 首 +32°・頭の位置 +29°）。人による線の位置の違いは消え、残るのは1本の中の揺れだけ。だから、この表は「自分のふつうの値から、線をどれだけ上に置けばよいか」を見るためのもの。

ふつうの走りの16秒平均（そろえたあと）：首 上から1% 48.1°・1本ごとの最大の真ん中 46.6°・いちばん大きい 58.1°、頭の位置 上から1% 49.8°・最大の真ん中 48.3°・いちばん大きい 59.5°

頭を前に出したとき（走り出して 250秒から 60秒、胸はそのまま、首の付け根で頭を前に回す）の、アプリの点の値の増え（真ん中）：+4°：首 +5.4°・頭の位置 +5.4°、+6°：首 +8.1°・頭の位置 +8.1°、+10°：首 +13.6°・頭の位置 +13.6°、+15°：首 +20.5°・頭の位置 +20.5°

誤った声は、ふつうの走りで頭の線で言った「頭が前に出ています」（走り出して 10秒から終わりまで）。気づいた割合は、頭を前に出していた間（と戻って5秒）に、頭の線で声が出た走りの割合（かっこは、出し始めから声までの秒の真ん中）。線は首の角度と頭の位置の両方を越えたときだけ言う（16秒平均）。1回の走りで 3回まで、そのあとは 300秒に1回。

線が低いと、ふつうの走りの揺れで早いうちに声が出て（1回の走りで3回まで、そのあとは5分に1回）、頭を前に出したときには言える回数が残っていないので、気づく割合も下がる（42°・46° で 60%）。
今の線（ふつうの値から +6°・+8°）は、誤った声が10分あたり 0.04回で、頭を +10° 前に出せば 96% で気づく。+4°（ふつうの値から +2°・+4°）まで下げると、+4° 前に出したのにも 74% で気づくが、
誤った声が 0.88回（77本のうち39本）に増える。

限り：仮想のスマホでは、頭を首の付け根で回した量より、アプリの点の値が 1.4倍ほど大きく増えた。自分の記録（下）では、頭のセンサーの傾きの変化に対して、カメラの値の変化は 0.3〜0.5倍ほどだった。
実機では、同じだけ頭を前に出しても、この表より線に届きにくい。

## 自分の記録で確かめた（2026-11-02 の2本と 2026-10-19、記録を今のコードに通し直した）

頭のセンサー（頭に付けた傾きのセンサー。立った姿勢からの前後の傾きを1秒ごとに出し、16秒で平均）と並べた。2026-11-02 20:23 の走りでは、カメラの首の角度（16秒平均）と、頭のセンサーの「頭 − 胸」の傾きの相関は −0.93（向きが逆なだけで、よく合う）。

- 20:23 の走り（走り出しは記録の約300秒）：ふつうに走った始めの40秒は、首 40〜42°・頭の位置 42〜44°。
  - 約355秒：頭を前に出した。頭のセンサーは走り出しより 25〜35° 前、カメラは 首 48〜55°・頭の位置 52〜59°。今の線で 356秒に声が出た。
  - 約440秒：頭を少し前に出した。頭のセンサーは直前より 6〜8° 前で、355秒のときの4分の1ほど。カメラは 首 41.4°・頭の位置 44.7°（16秒平均の山）で、走り出しのふつうの値と同じ。
    スマホの向きの値（前側・後ろ側）も同時に 0.05 → 0.02 と動いていて、それで直しても、走り出しより +2〜3° しか増えていない。
  - 線を変えて通し直すと、約440秒に声が出るのは 40°・44° だけ（432秒）。42°・46° 以上では出ない。
- 18:43 の走り：ふつうに走った区間の首は 42〜45°・頭の位置は 42〜45°（頭のセンサーは走り出しと同じ）。頭を前に出した区間は 首 50〜60°（頭のセンサーは +20〜37°）で、今の線で3回とも声が出た（540・602・633秒）。
  40°・44° にすると、523秒の、頭のセンサーではふつうの区間でも声が出た（誤り）。50°・54° では 633秒の声が、52°・56° では 540秒の声もなくなった。
- 2026-10-19（`npm run grade -- --set headNeck=… --set headLean=…`）：その日のふつうの値は低く（今日の基準 首 34.3°）、40°・44° 〜 48°・52° のどれでも、ふつうの区間の頭の線の声は0、頭を前に出した区間は10秒で見つけた。

ふつうの値は日によって 8° ほど違う（10-19 は首 約34°、11-02 は約42°。11-02 はスマホの向きの値が +0.07〜0.10 で、前側から撮っていた分だけ大きく出ている見込み）。
決まった線を下げると、ふつうの値が高い日に、ふつうに走るだけで声が出る。

結論：今の線（48°・52°）のままにする。約440秒の頭の下がりは、カメラではふつうの走りの揺れと分けられない大きさだった（頭のセンサーでは分かる）。
