# 腰の決まった線：立脚中期の腰の高さ（仮想実験 sim/hip-abs.sim.ts）

研究データのふつうの走り（RBDS：時速9・12.6・16.2km、Riglet：楽・速い〔印から見積もって時速約8.1・9.8km〕、Van Hooren：時速12km）の最初の60秒までを、実機の記録のコマの間隔（平均毎秒12.5コマ）の仮想のスマホ（真横・1.2m・高さ80cm・超広角、点のぶれ1%）で映し、アプリと同じ立脚中期の腰の高さ（腰の中心から立脚側の足首までの高さ ÷ 立脚側の脚の長さ。geometry の midstance、1秒ごとに平均）を出した。窓は続いた 16 個の1秒の平均（HIP_ABS.window）。
