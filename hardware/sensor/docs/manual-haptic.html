1. 決めたこと

項目決めたこと（理由）
子基板Fタイプ基板を切らずに縦長（横6×縦8穴、18×23.5 mm）で使う。ノード（17×24.5 mm）とほぼ同じ大きさなので、ノードの肌側にそのまま重ねられる。穴は左から A〜F、上から 1〜8 と呼ぶ
表（部品の面）ユーザーが並べた形のまま：左のふちにスライドスイッチ（横に寝かせ、つまみを左の外へ）、上の段に 10µF、その下に 2SC1815、中ほどに 1kΩ
裏（はんだの面）モーターを貼る（下の部分）。肌側をモーターだけにし、部品とスイッチを外（ノードの側）に向けるため。モーターの下になる穴には何も挿さず、近くの足は短く切って、平らに貼る
スイッチSS12D01G4 を表の左のふちに横向きに寝かせ、足を直角に曲げて B2・B3・B4 に挿す。つまみは基板とノードの外形より外に出し、横から指でつまんで動かす。裏に付けると、つまみが肌の側を向いてしまう
モーターを鳴らすピンXIAO D7（3V3・GND と同じ列の奥の角。隣の D8 は使っていない）
3V3・GND の取り口センサー基板の 3V3・GND の穴の裏（部品の面）。子基板のすぐ上に来る面なので線が短い。XIAO の角の接点にはもう赤・黒が付いている
INT1センサーの INT1 の穴（XIAO の下）→ XIAO D1。センサーの部品の面から付けて、ふちを回す
電池電池の赤 → スイッチの真ん中の足（B3）→ 端の足（B2）→ XIAO の BAT+。黒はそのまま BAT−。電池はノードの横（USB の側）に置く
重ね方肌の側から モーター → 子基板 → ノード（センサー → XIAO）。XIAO の部品の面が外

2. 回路図

図1：回路図。（ ）の中は子基板の穴の名前（図2）。D7 が HIGH の間だけモーターが回る。ダイオードは要らない（モーターの中の駆動IC FD216 がコイルを駆動する）。10 µF は、モーターが回り始めるときに 3V3 が下がらないように。INT1 は子基板を通らない。

3. 子基板（切らずに縦長で使う）

図2：子基板の穴の配置。左が表、右が裏（裏から見ると A〜F が逆）。点線の丸は裏に貼るモーターの位置。モーターの下（A6〜E8 あたり）の穴は空ける。

写真から変えた点

  • スイッチの足は B 列（B2・B3・B4）：横に寝かせると足が右を向くので、直角に曲げて隣の B 列に挿す。本体は A 列の上に乗り、A2〜A4 の穴は使わない。
  • 10µF は C1・E1（写真とほぼ同じ）、2SC1815 は C3・D3・E3（平らな印字面を 1kΩ の側（下）へ。写真では 10µF の側を向いているが、それだと E と B が逆になる）、1kΩ は B5〜E5。モーターの縁から離れた穴を選んだ（B5 だけは縁から約 0.7 mm なので、裏の足は根元で切り、D7 の線は表で付ける）。
  • モーターは裏。写真の位置（中心 C7、端子は右）のまま裏に貼る。端子の線は、端子のすぐ上と下の F6・F8 に通す。

6. 安全の注意

はんだ付けや線を足す作業は、スイッチを切ってから：スイッチを付ける前（工程3の途中まで）は、電池が付いている個体は USB を外し、10分つながず動かさずに置いて眠らせてから作業する。こて先で隣の接点とつながないように。電池の線は引っぱらない。
スイッチを切っていると、USB をつないでも充電されない：充電はスイッチを入れてから（スイッチが電池と XIAO の間にあるため）。
電池の線は1本ずつ切る：2本いっしょに挟むと刃の上でショートする。1本切ったら、その先をすぐテープで包む。
モーターの＋−を逆にしない：中に駆動IC があり、極性があります（秋月の注意）。＋を F8、−を F6。
5V には何もつながない：つなぐのは 3V3・GND・D7・D1・BAT+ だけ。

工程1. モーター6個に線を付け、感じるか確かめる

図8：モーターの極性（秋月 LBV10B-009.png をもとに描いた）。
  1. 6個とも、ばね端子の先に赤・黒の線（各 3 cm、先 2 mm むいて予備はんだ）を短く（1〜2秒）付ける。付け根を細いテープで押さえる。要確認：ばねにはんだが乗るか。長く温めるとばねが弱るおそれ。
  2. どれか1個のノードを USB で Mac につなぎ、赤を XIAO の3V3、黒をGNDの接点に指で当てる（5V には当てない）。6個のモーターを順に当てる。
成功のしるし：当てるとブーンと震える。手首（足首）に当てて、止まっているときに感じるかを見る。回らなければすぐ離し、極性を見直す。

工程2. 子基板を6枚組む

表の部品 → 裏の配線 → モーターの順。6枚まとめて同じ順で進める（図2）。

  1. スイッチ：つまみを左の外へ向けて横に寝かせ、3本の足をラジオペンチで直角に曲げて B2・B3・B4 に表から挿す（本体は A 列の上、つまみは基板のふちから外へ出る）。足が入りにくければ、端の足を少し曲げる。
  2. 10µF：C1・E1 に表から挿す（足の間 5 mm のまま。向きは自由）。
  3. 2SC1815：足を少し広げて 2.54 mm にし、平らな印字面を 1kΩ の側（下、5行目の側）に向けて C3・D3・E3 に挿す。基板の下のふちの側から印字面を見ると、左から E・C・B ＝ C3・D3・E3（図9）。確かめ方：基板を表から見て、印字面が 1kΩ の側を向いていれば正しい。
  4. 1kΩ：B5・E5 に寝かせて挿す。
  5. 裏ではんだ付けし、足を折って配線する（3章の表）：
    • E の足（C3）を C1 まで、10µF の C1 の足を B1 まで折って付ける（GND）。
    • 10µF の E1 の足を F1 まで折って付ける（3V3）。
    • B の足（E3）にチューブをかぶせ、E5 まで折って 1kΩ の足に付ける。
    • 赤い線（3 cm）を F1 から、基板のふちの外側を通して F8 へ。黒い線（3 cm）を C の足（D3）から D4 を通って右へ、F6 へ（B の足のチューブの上をまたぐ）。この2本は F6・F8 の穴に通さず、裏のランドにのせて付ける（穴はモーターの線に使う）。
    • B5 の足は裏で根元から切る（モーターの縁に近いため）。ほかの足も 1 mm 程度に短く切る。
  6. 外へ出す線を付ける：B1 に GND（黒 6 cm）、F1 に 3V3（赤 6 cm）、B2 に BAT+（赤 6 cm）、B5 の表の 1kΩ の足に D7（白 6 cm）。電池は工程6。
  7. モーター：裏の、モーターが乗る範囲（A5〜E8 のあたり）をカプトンテープで覆う。モーターの両面テープで、中心が C7、端子が F 列の側になるよう裏に貼る（表から見て右。裏から見ると左になる。図2の右の図）。端子の短い線を、すぐ横の穴に裏から通して表ではんだ付けする：＋ → F8、− → F6。
図9：2SC1815 の足の並び。
確かめる（6枚とも）：C1・D1・E1、C3・D3・E3、B2・B3・B4 の間がはんだでつながっていない（ルーペかカメラで）。モーターが浮かずに平らに貼れている。

工程3. 6個のノードに線を付ける

6個まとめて、同じ順番で付けます（図4・図5）。子基板はノードの下（肌の側）に、部品の面をノードに向けて置き、線の長さを合わせる。

  1. INT1：緑の線（6 cm）を、センサーの部品の面の「INT1」のランドに付ける（XIAO の下の穴なので、下から）。部品の面に沿わせ、手前（D0〜D6 の列）のふちから表へ回し、XIAO D1（手前の列、USB から2番目）に付ける。途中をカプトンテープで押さえる。
  2. 子基板 F1 の 3V3（赤）：センサーの3V3 の穴の裏のランドに付ける（表には今の赤が付いている）。
  3. 子基板 B1 の GND（黒）：センサーのGND の穴の裏のランドに付ける。
  4. 子基板 B5 の D7（白）：XIAO D7（奥の列、USB の反対の角）に付ける。
  5. 子基板 B2 の BAT+（赤）：XIAO の裏の BAT+ へ。個体によって2通り（図6）。
    • 電池がもう付いている個体：USB を外して眠らせてから（作業で動かすと起きるので、手早く）、電池の赤だけを真ん中あたりで切り、電池側の先をすぐテープで包む。XIAO 側の赤を B2 の赤と、熱収縮チューブを先に通してからつなぐ。電池側の赤は工程6で B3 へ。黒は切らない。
    • 電池がまだの個体：XIAO をセンサーから静かにはがし（線は付いたまま）、裏の BAT+ に B2 の赤、BAT− に受け線の黒（6 cm、先はテープで包む）を付けて、貼り直す。
確かめる（6個とも）：XIAO の D1・D7 の隣（D0・D2、D8）にはんだが渡っていない。センサーの 3V3 と GND のランドがつながっていない。電池側の赤の先が包まれている。

工程4. 1個ずつ、振動と INT1 を確かめる

cd ~/Developer/run-form-coach/hardware/sensor
tools/flash.sh 04_haptic_check
tools/monitor.sh
成功のしるし：①書き込むとモーターが短く3回鳴り、LED も3回点く。モニタに buzz x3、LSM6DSV16X found、threshold 2.00 g。②ノードを机に軽く「トン」と打つと、INT1 #1 と出て、LED が点き、短く1回鳴る。静かに置けば鳴らない。
起きたこと確かめること
3回鳴らない（LED は点く）D7 の線、トランジスタの向き（印字面が 1kΩ の側を向いているか。10µF の側を向いていると E と B が逆で鳴らない）、E と B の足の折り、F6・F8 の線、モーターの極性。モニタで b を打つと1回鳴らせる
鳴りっぱなし子基板の C と E（D3・C3）がつながっている
鳴った瞬間に XIAO が再起動する3V3 が下がっている。案：子基板の 3V3（赤）を XIAO の裏の BAT+ に付け替える
トンで鳴らないINT1 の線（緑）。モニタの INT1 pin が 0 のままか。- を打ってしきい値を下げる
何もしなくても鳴る+ を打ってしきい値を上げる（0.25 g ずつ）

しきい値は書き込み直すと 2.0 g に戻ります。走るときの値（足首は着地で 10 g を超えうる）は、まだ決めていません。ちょうどよかった値をチェック表に書いておきます。

工程5. 1個ずつ、03_ble_imu を書き直す

tools/flash.sh 03_ble_imu 1     # 1番。2〜6番は番号を変える

tools/viewer.sh で RFC-IMU-番号 が出て、約100サンプル/秒・抜け 0 件になるのを見る（前の手順書の手順6）。03_ble_imu はモーターを鳴らしません。走りながら振動を試すときは 04_haptic_check を書き込みます。

要確認：03_ble_imu のとき、モーターが勝手に鳴らないこと（D7 は何も出さないので、鳴らないはず）。

工程6. 1個ずつ、電池とスイッチ

  1. スイッチをどちらか一方に寄せておく。
  2. 電池の赤 → 子基板 B3（スイッチの真ん中の足）：熱収縮チューブを先に通し、裏の B3 の足の根元に付けて、チューブを縮める。
  3. 電池の黒：電池がまだだった個体は、BAT− の受け線の黒と、チューブを先に通してからつなぐ（もう付いている個体は、そのまま）。
  4. USB を外したまま、つまみを動かす。入で XIAO の LED が点き（03_ble_imu なら受信画面に出る）、切で消える。横から見て、入の向きに矢印と「入」をマスキングテープで書いて貼る（要確認：つまみの位置と入・切の向きは、実物で決まる）。
  5. 受信画面で「電池：3.xx V」と出るのを見る。充電するときはスイッチを入れてから USB をつなぐ。
眠る・起きる とスイッチ：03_ble_imu は「つながらず、動かないまま10分」で眠り、手に取る・付けて歩き出すくらい動くと起きる（INT1 の線で起こす）。長くしまうときはスイッチを切る（眠っていても、動きを見張るぶん少し電気を使うので）。

工程7. 重ねて体に付ける

  1. 子基板の部品の上にクッションの両面テープを重ね、ノード（センサーの部品の面）を貼る。子基板を約 2 mm スイッチの側にずらし、スイッチのつまみがノードの外形より外に出るようにする（図7）。
  2. 電池をノードの横に並べ、テープで留める。線を引っぱらない。
  3. 袋に入れ、モーター（子基板の裏）が肌に当たる向きでバンドに巻く（XIAO の面が外）。袋の上から、つまみを横からつまんで動かせるか確かめる。
