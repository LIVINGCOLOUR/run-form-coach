体に付けるセンサーの作り方

XIAO nRF52840 ＋ 6軸センサー（LSM6DSV16X）で、動きの値を Bluetooth で Mac に送るまで。1個目はブレッドボードで、2個目からは空中配線・電池つきで体に付ける

0. この手順書でやること

6か所（両手首・両足首・首・胸）に付けるセンサーを作ります。手順1〜8 は最初の1個で、ブレッドボードの上で、Mac の USB かモバイルバッテリーで動かします。2個目からは「2個目からの作り方」の章で、ブレッドボードを使わずに線を直接はんだ付けし、電池をつけて体に付けます。

2. 安全の注意（先に読む）

センサーに 5V をつながない：センサーは 3.3V 専用です。XIAO の 5V ピンにつなぐと壊れます。必ず 3V3 ピンにつなぎます。
センサー基板のジャンパーは「6A」と「I2C」だけ：「6B」と「6A」を両方ふさぐと、アドレスの線がぶつかります。「CS」をふさぐと I2C で動かなくなります。裏の「SDX」「SCX」の四角もふさぎません。
電源を入れる前に、テスターでショートを確かめる：はんだ付けの後、3V3 と GND の間がつながっていない（導通しない）ことを確かめます。
  • XIAO の USB-C の差し込み口は小さくて外れやすいので、ケーブルを横にこじらない。
  • 基板を触る前に金属に触れて、静電気を逃がす。

手順1. Mac の準備（約15分、最初に1回だけ）

ターミナルで次を実行します。

cd ~/Developer/run-form-coach/hardware/sensor
tools/setup.sh

このスクリプトは、次の4つをします。

  1. Rosetta を入れる：XIAO 用のコンパイラーが Intel の Mac 向けにしか作られていないため、Apple シリコンの Mac では必要です（この Mac には、2026-10-09 に入れました）。
  2. arduino-cli（Arduino のコマンド版）を入れる（入れ済み）。
  3. XIAO nRF52840 のボードのパッケージ（Seeed nRF52 Boards）を入れる（入れ済み）。
  4. ボードのパッケージが python という名前を呼ぶのに、Mac には python3 しかないので、tools/bin/python でつなぐ。
なぜ Arduino IDE（画面で操作するほう）を使わないか：上の 1 と 4 の問題で、Mac の Arduino IDE ではコンパイルが止まる可能性が高いからです。この手順書のコマンドは、作者の Mac で実際に通してあります。
成功のしるし：最後に「== 準備ができました」と出る。

手順2. XIAO だけで書き込みを確かめる（はんだ付けの前に）

  1. XIAO を、データ転送対応の USB-C ケーブルで Mac につなぐ。
  2. ターミナルで書き込む： 
    tools/flash.sh 01_blink
  3. XIAO の文字を見る（終わるときは Ctrl+C）： 
    tools/monitor.sh
成功のしるし：XIAO の小さな LED が1秒ごとに点滅し、モニタに XIAO is alive: 0, 1, 2… と出る。

「XIAO が見つかりません」と出たら：①ケーブルが充電専用でないか、②XIAO のリセットボタン（USB の横の小さなボタン）を素早く2回押して書き込み待ちにしてから、もう一度 tools/flash.sh 01_blink。

2個目の XIAO でも同じことをします。どちらも動けば、XIAO は良品です。

手順3. はんだ付け

3-1. XIAO にピンヘッダー

  • XIAO は、両側のふちに7個ずつ、14個の穴すべてにピンを付けます。ピンヘッダー（1×40）をニッパーで7ピンずつ2本に切る。
  • XIAO を部品の面を上（USB-C の差し込み口が見える側）にして、ピンヘッダーを先に XIAO の穴へ下から通します（黒い樹脂は XIAO の下側、短いほうのピンが上に少し出る）。
  • そのまま、ブレッドボードのまん中の溝をまたぐ向きで挿す（左右の列が溝の両側に分かれる）。こうするとピンがまっすぐに保たれ、手を離してもはんだ付けできます。
  • 上から14か所をはんだ付けする。はじめに対角の2か所を付けて、XIAO が浮いていない・傾いていないのを見てから残りを付けます。

3-2. センサー基板にピンヘッダー

  • 付属のピンヘッダーは、最初から3ピンずつ4本に分かれていることがあります。そのときは切らずにそのまま使います。1本につながっているときは、ニッパーで3ピンずつに切り離す。
  • 基板の4か所の3ピンの穴（左右に2組ずつ）すべてに付けると、ブレッドボードの上で安定します。XIAO と同じく、先に基板に通してからブレッドボードに挿してはんだ付けします。

3-3. センサー基板のジャンパーをふさぐ（大事）

この基板は、ジャンパーをふさがないと I2C で動きません。小さな四角い接点のすき間を、はんだで橋渡しします。基板に「J1」などの番号は印字されていません。下のふちに、左から「6B」「6A」「I2C」「CS」と印字された接点の組があります。

基板の印字役割（回路図の番号）どうする
6AI2C のアドレスを 0x6A にする（J3）。接点2つふさぐ（すき間1つ）
I2CSDA と SCL のプルアップ抵抗（10kΩ）をつなぐ（J1）。接点が3つ並んでいるふさぐ（すき間2つとも）
6Bアドレスを 0x6B にする（J2）ふさがない（6A と同時は不可）
CSCS を GND につなぐ（J4、SPI 用）ふさがない（ふさぐと I2C で動かない）
裏の「SDX」「SCX」の四角補助の端子を GND につなぐ（J5・J6）ふさがない

CS は基板の上で 10kΩ で 3.3V に引き上げられているので、何もつながなければ I2C になります。プログラムは 0x6A と 0x6B の両方を探すので、6A の代わりに 6B をふさいでも動きます。

3-4. 確かめる

テスターで：

  • XIAO の 3V3 と GND の間が導通しない
  • センサーの 3V3 と GND の間が導通しない
  • 「6A」と「I2C」（すき間2つとも）がふさがっている（両側が導通する）。「6B」「CS」はふさがっていない
  • 隣どうしのピンが、はんだでくっついていない

テスターが無くても進めるとき（目で見る）：明るいところでスマホのカメラで拡大して、①「6A」のすき間と「I2C」のすき間2つが、つやのあるはんだの山でつながっている、②「6B」「CS」と裏の「SDX」「SCX」には、すき間が見えている、③XIAO とセンサーのピンの根元で、隣のピンとはんだがつながっていない、を確かめる。ショートは目では見落としやすいので、手順5で USB をつないだら XIAO とセンサーを指で触り、熱くなったらすぐ抜く。

手順4. 配線（ブレッドボード）

つなぐのは4本だけです。センサー基板のピンの名前は、基板に印刷された文字を見て確かめてください。

XIAO のピン→センサー基板のピン線の色（おすすめ）
3V3（右側の上から3番目）→3V3赤
GND（右側の上から2番目）→GND黒
D4 = SDA（左側の上から5番目）→SDA青
D5 = SCL（左側の上から6番目）→SCL黄

XIAO のピンの位置は、部品の面を上・USB-C を上にして見たときのものです。左側は上から D0〜D6、右側は上から 5V・GND・3V3・D10・D9・D8・D7 の順です。5V（右側のいちばん上）には何もつなぎません。センサーの CS・SDO/SA0・INT1・INT2・SDX・SCX・SDO_AUX・OCS_AUX はつなぎません。

図：つなぐのは 3V3・GND・SDA・SCL の4本。センサー側のピンの実際の並びは、基板の印刷を見て合わせる。

つなぐ前にもう一度：赤い線が XIAO の 3V3（5V ではない）につながっているか、目で確かめる。

手順5. センサーの値を見る

tools/flash.sh 02_check_lsm6dsv
tools/monitor.sh
成功のしるし：次のように出る。 
Start!

机に置いたまま動かさないと、加速度のどれか1つが約 1.00（重力）、ほかの2つは約 0、ジャイロ（後ろの3つ）はほぼ 0。基板を傾けると加速度が、回すとジャイロが大きく変わる。
出たもの意味と、やること
LSM6DSV16X not found が繰り返されるセンサーが見えていない。①4本の配線、②「6A」と「I2C」（すき間2つとも）がふさがっているか、③SDA と SCL が逆になっていないか、④センサーの 3V3 に電圧が来ているか（テスターで約3.3V）を確かめる
WHO_AM_I = 0x... が 70 以外別のチップか、通信が乱れている。配線を短くし、はんだ付けを見直す
値がずっと 0 のまま初期設定が効いていない。XIAO のリセットボタンを1回押して、もう一度見る

手順6. Bluetooth で Mac の Chrome に送る

  1. Bluetooth で送るプログラムを、番号 1 を付けて書き込む（名前が RFC-IMU-1 になる）： 
    tools/flash.sh 03_ble_imu 1
  2. 受信画面を開く（Chrome が自動で開きます。終わるときはターミナルで Ctrl+C）： 
    tools/viewer.sh
  3. 画面の「接続」を押し、一覧の RFC-IMU-1 を選んで「ペア設定」。
成功のしるし：加速度とジャイロの数字が動き、「受信：約100 サンプル/秒」で、「抜け：0 件」のまま増えない。「加速度の範囲：±16 g」と出る。
1回の通知に何サンプルかまとめて届くので、横に出る「通知 ○ 回/秒」は 100 より少なくて構いません。プログラムの SAMPLE_HZ を 50 にして書き込んだときは、約50 サンプル/秒が正常です。
  • 一覧に何も出ないとき：Mac の「システム設定 → プライバシーとセキュリティ → Bluetooth」で、Google Chrome を許可する。Mac の Bluetooth が入っているかも確かめる。
  • XIAO の LED が速く点滅し続けるとき：センサーが見つかっていない。手順5に戻る。
  • 10分つながないと眠ります（電池の持ちのため）。一覧に出なくなったら、XIAO のリセットボタンを1回押すか、USB をつなぎ直すと起きます。
  • 受信画面は、Web Bluetooth の決まりで https か localhost でしか動きません。viewer.html をダブルクリックで開くのではなく、必ず tools/viewer.sh から開きます。

手順7. モバイルバッテリーで動かす

  1. XIAO を Mac から外し、モバイルバッテリーにつなぐ（書き込んだプログラムはそのまま残っています）。
  2. Mac の受信画面で、もう一度「接続」。
  3. 5分そのまま置いて、切れないか見る。
モバイルバッテリーが勝手に切れることがある：XIAO はとても少ない電気で動くので、バッテリーが「充電が終わった」と思って 30秒〜1分で切れることがあります。「低電流モード」（小型機器モード）があれば使ってください。

手順8（できれば）. トレッドミルで記録する

  • XIAO とブレッドボードとモバイルバッテリーを、ウエストポーチなどに入れて体に固定する（ぶら下げると揺れが雑音になる）。
  • 受信画面の「記録を始める」→ 走る → 「記録を止める」→「CSVで保存」。
  • CSV には、時刻（ミリ秒）、加速度 3軸（g）、ジャイロ 3軸（dps）が入ります。1秒に約100行（1サンプル1行）です。ファイル名にセンサーの名前（RFC-IMU-2 など）が入ります。

A. XIAO だけで書き込みを確かめる

手順2と同じです。はんだ付けの前に tools/flash.sh 01_blink で LED が点滅するのを見ておきます。

B. センサーのジャンパー（1個目と同じ）

下のふちの「6A」と「I2C」をはんだでふさぎます。I2C は接点が3つで、すき間2つともふさぎます。「6B」「CS」、裏の「SDX」「SCX」はふさぎません。くわしくは 3-3 の表。

C. コードを XIAO にはんだ付けする

センサー側は、白いコネクターを挿すだけです。XIAO 側を、ピンヘッダーなしで穴に直接はんだ付けします。

コードの色→XIAO の穴XIAO の上での位置（部品の面を上、USB-C を上にして）
黒→GND右側の上から2番目
赤→3V3（5V ではない）右側の上から3番目
青→D4（SDA）左側の上から5番目
黄→D5（SCL）左側の上から6番目

色は Qwiic の決まり（黒 GND・赤 3.3V・青 SDA・黄 SCL）です。秋月の商品ページは、この基板のコネクターを「Qwiic 準拠」としています。

  1. コードを、コネクターから 5cm ほどのところで切る（4本まとめて切ってよい。電池の線とちがって電気は来ていない）。体に付けないで試すだけなら、切らずにオスピンのまま XIAO の穴に挿してはんだ付けしてもよいが、長さが余ってかさばる。
  2. 4本を少し裂いて離し、それぞれ先の皮を 3mm むく。細い線なので、より合わせてから先にはんだを少しのせる（予備はんだ）。
  3. 熱収縮チューブ（φ1.5、1cm）を、はんだ付けの前に線に通しておく。付けた後では通せない。
  4. 線を XIAO の部品の面から穴に差し、部品の面ではんだ付けする。裏に突き出た先は、ニッパーで短く切る（背中合わせに重ねたときに当たらないように）。
  5. チューブを根元までずらし、はんだごての横腹を近づけて縮める（こて先を直接当てない）。
  6. 手順3-4 と同じく、目かテスターで、隣どうしがくっついていない・3V3 と GND がつながっていないのを確かめる。
  7. USB をつないで tools/flash.sh 02_check_lsm6dsv と tools/monitor.sh（手順5）で、センサーが見えるのを確かめる。

D. 名前を付けて書き込む

何個目かの番号を付けて書き込むと、その番号の名前（RFC-IMU-2 など）になります。プログラムを書き換える必要はありません。

tools/flash.sh 03_ble_imu 2     # 2個目。3個目なら 3、…

tools/viewer.sh で、一覧に RFC-IMU-2 が出て、1秒に約100サンプル・抜け 0 件・「加速度の範囲：±16 g」になるのを確かめます（手順6と同じ）。

番号と付ける場所を決めて、ラベルを貼ります（案）。袋の外にも同じラベルを貼ると、付けるときに迷いません。

名前付ける場所メモ
RFC-IMU-2胸先に2個で「胸と首の差」（猫背）を試す
RFC-IMU-3首
RFC-IMU-4左足首着地の衝撃を測る
RFC-IMU-5右足首
RFC-IMU-6左手首
RFC-IMU-1右手首1個目を、空中配線・電池つきで作り直したとき

ラベルには、体に付けたときの上（頭の方向）を指す矢印も書いておきます。毎回同じ向きに付けると、記録どうしを比べられます。

E. 電池をつなぐ

プラスとマイナスを逆につなぐと、その瞬間に XIAO が壊れます：赤 ＝ BAT+、黒 ＝ BAT−。電池の保護回路は、逆につないだのを防いではくれません。3V3 や 5V のピンにはつなぎません（必ず裏の BAT の接点）。
電池のコネクターは、線を1本ずつ切る：2本いっしょにニッパーで挟むと、刃の上でプラスとマイナスがつながってショートします（火花・発熱）。1本切ったら、その先をすぐテープで包んでから、もう1本を切ります。

BAT の接点の位置（Seeed の公式資料のピン配置図「XIAO nRF52840 Back」で確認）：XIAO を裏返して、USB-C を上にして見ると、右側のふち（表の D0〜D6 の裏側）の、上から3つ目と4つ目のピンの内側に、小さな四角い接点が縦に2つ並んでいます。上が BAT−、下が BAT+。基板に「−」「+ BAT」と印刷されています。

図：XIAO nRF52840（無印）の裏。Seeed の「XIAO_nRF52840_back_pinout」をもとに描いたもの。Plus・Sense Plus は位置が違う。

  1. 電池の＋−を確かめる：テスターがあれば、電池の赤と黒の線の電圧を測り、赤をテスターの赤に当てて +3.x V（マイナスでない）になるのを見る。テスターが無いときは、線の色と、電池本体の、線が出ている所の近くの「＋」「−」（「B+」「P+」なども同じ意味）の印刷を見て、赤が＋につながっているのを確かめる。どちらかがはっきりしないときは、つながない。
  2. XIAO の USB を外す。電池がふくらんでいたら使わない。
  3. コネクターの根元で、線を1本ずつ切る（上の注意）。線は 3〜4cm 残す。
  4. XIAO の裏の BAT の2つの接点に、先にはんだを少しのせておく。
  5. 黒（BAT−）から付ける：黒の先を 2mm むいて予備はんだし、BAT− の接点にのせて、こてで温めて付ける。この間、赤の先はテープで包んだまま。
  6. 赤（BAT+）：テープを外し、同じように 2mm むいて BAT+ に付ける。付けた瞬間から XIAO が電池で動き出す。
  7. 2本の線を、XIAO の裏にテープで押さえる（線を引っぱると接点ごとはがれるので、根元に力がかからないように）。
  8. Mac の受信画面でつながるのを確かめる（電池だけで動いている）。「電池：3.xx V」と出る。

充電

  • XIAO を USB-C で Mac か USB 充電器につなぐだけで充電します。充電の間は、XIAO の USB の横の赤い小さな LED（充電の LED）が点き、満タンになると消えます。
  • 充電の電流は、何もしなければ約 50mA です（Seeed の資料：P0.13 を何もつながない入力にすると約 50mA、出力の LOW にすると約 100mA。ボードのパッケージは起動時に P0.13 を入力にし、このフォルダーのプログラムは P0.13 を触らない）。110mAh の電池には約 0.45C で、無理のない速さです。空から満タンまで2時間半〜3時間ほど。100mA には上げません（110mAh には約 0.9C で、余裕がない）。
  • P0.14 の注意（Seeed の公式資料）：P0.14 は電池の電圧を読む道を開け閉めするピンで、HIGH にしたまま充電すると、電圧を読むピン（P0.31）が上限の 3.6V に届いて壊れるおそれがあるので、いつも LOW にしておくように、とあります。ボードのパッケージは起動時に P0.14 を HIGH にするので、このフォルダーのプログラム（01・02・03）は、起動してすぐ P0.14 を LOW にします。ほかの人のプログラムを、電池をつないだ XIAO に書き込まないでください。
  • 充電中は目を離さない。燃えるものの近くで充電しない。袋に入れたまま・体に付けたまま充電しない。
  • ふくらんだ電池、熱くなる電池は使わない。落とした・つぶした電池も使わない。
  • 電池の電圧は受信画面に出ます：4.2V で満タン、3.5V を切ったら充電。USB につないでいる間は、充電の電圧（4V 台）が出ます。

眠る・起きる（スイッチの代わり）

電池をはんだ付けすると、スイッチが無いので、ずっと電気が流れます。そこで 03_ble_imu は、だれともつながらないまま10分たつと眠ります（センサーも止める）。起こすには、XIAO のリセットボタンを1回押すか、USB をつなぎます。走る前に起こしてから袋に入れると楽です。眠っている間もわずかに電気を使うので、何週間も使わないときは、月に1度は充電します。

F. 重ねて、体に付ける

  1. XIAO とセンサーを背中合わせに、厚手の両面テープで貼る（XIAO の裏とセンサーの裏が向き合う）。コードは横に折りたたむ。
  2. 電池をセンサーの表側に、両面テープで重ねる。はんだの尖った先が電池に当たらないように、間にテープを1枚はさむ（電池の袋に穴があくと発火のおそれ）。
  3. 体側から 電池 → センサー → XIAO の順になるように付け、XIAO の部品の面を外に向ける（アンテナが体や電池でふさがれないように）。
  4. ミニチャック袋に入れ、ラベルを袋の外にも貼る。
  5. 面ファスナーのバンドで、ずれないように、しっかり体に巻く。揺れると、その揺れが雑音として記録に入ります。

加速度の範囲（±16 g）について

足首の着地は 10 g を超えることがあるので、03_ble_imu は全部の個体で加速度の範囲を ±16 g にしています（前は ±8 g）。細かさは 1 あたり 0.000488 g（±8 g のときは 0.000244 g）になりますが、走る動きを見るには十分すぎる細かさで、困りません。範囲は通知ごとに送るので、受信画面と CSV はどちらでも正しい g を出します。

あとでやること

  • 小さくする：センサーを白猫屋の小さい基板（13×18mm）にするなら、ピンの並びと I2C 対応をショップに確かめてから。
  • 電池の持ち：まだ測っていない。最初のランの前後で受信画面の電池の電圧を書き留め、何時間持つかを見る。

Bluetooth で送る中身

1回の通知に、続いたサンプルを N 件まとめて入れます（N =（通知の長さ − 7）÷ 13）。Mac との MTU が 23 のままなら1件（7 + 13 = 20 バイト）、247 まで広がれば最大18件です。

バイト中身単位
0〜1先頭のサンプルの通し番号（符号なし16ビット）。1サンプルごとに1増え、65535 の次は 0。k 件目は「先頭の番号 + k」番号が飛んだら、そのぶん抜け
2〜5先頭のサンプルの時刻（XIAO の起動からのミリ秒、符号なし32ビット）ms
6加速度の範囲（符号なし8ビット）。8 か 16g（±8 g / ±16 g）
ここから1件13バイトを N 件（k 件目は 7 + 13k バイト目から）
+0先頭のサンプルからの時刻の差（符号なし8ビット）。そのサンプルの時刻 = 先頭の時刻 + これms
+1〜6ジャイロ x・y・z（符号付き16ビット ×3）1 = 0.07 dps（範囲 ±2000 dps）
+7〜12加速度 x・y・z（符号付き16ビット ×3）±16 g なら 1 = 0.000488 g、±8 g なら 1 = 0.000244 g
キャラクタリスティック中身単位
0xFFE1（通知）上の表の、センサーの値
0xFFE2（読み取り・通知）電池の電圧（符号なし16ビット）。10秒ごとに測り直す。USB につないでいる間は充電の電圧mV

サービス 0xFFE0。すべてリトルエンディアン。センサーは 960Hz で測り、XIAO がそのうち 10ミリ秒ごと（SAMPLE_HZ = 50 なら 20ミリ秒ごと）の最新値を読んでためておき、まとめて送ります。送るのが遅れても、ためた分（約2.5秒）までは抜けません。
