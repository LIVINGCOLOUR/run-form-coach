IMU Viewer

各センサーの「つなぐ」を押してください（出てきた RFC-IMU-番号 を選ぶ）
付ける6か所の枠が決まった場所に並びます（どこにどの番号を付けているかは、viewer.html の SLOTS で変える）。「つなぐ」を押すと、その番号のセンサーだけが選ぶ画面に出ます（Chrome の決まりで、選ぶ画面は1個ずつ）。
置いたまま動かさないと、加速度のどれか1つが約 1.00（重力）、ジャイロはほぼ 0 になります。
受信が 1秒に約100サンプル（03_ble_imu の SAMPLE_HZ を 50 にしたときは約50）で、「抜け」が 0 のままなら正常です。
1回の通知に何サンプルかまとめて届くので、通知の回数はサンプル数より少なくて構いません。
電池は 4.2V が満タン、3.5V を切ったら充電します。USB につないでいる間は、充電の電圧が出ます。
記録は、つないでいる全部のセンサーをまとめて1つの CSV にします（1列目がセンサーの名前。time_ms はセンサーごとの起動からの ms、pc_ms は受け取ったときの PC の時計）。
